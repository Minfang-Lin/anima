# 在自己电脑上做视频（剪映配音版）

思路：电脑上用脚本把动画录成**无声的高清视频**，配音、背景音乐和字幕都在**剪映**里做。
每一幕的时长可以按剪映朗读的长度来定，这样画面和声音正好对上。

---

## 一、准备工作（只做一次）

### 1. 安装 Node.js
到 <https://nodejs.org/zh-cn> 下载 **LTS 版**，一路“下一步”安装。
装好后打开“终端”（Mac：启动台搜“终端”；Windows：开始菜单搜 “PowerShell”），输入：

```bash
node -v
```

能看到 `v20.x.x` 这样的版本号就行。

### 2. 安装 ffmpeg（把画面合成视频的工具）
- **Mac**：先装 Homebrew（<https://brew.sh/zh-cn/>），再运行 `brew install ffmpeg`
- **Windows**：在 PowerShell 里运行 `winget install Gyan.FFmpeg`，装完**关掉 PowerShell 重新打开**

输入 `ffmpeg -version` 能看到版本信息就行。

### 3. 拿到项目文件夹并安装依赖
把项目文件夹（`anima`）解压到一个好找的地方，比如桌面。在终端里进入这个文件夹：

```bash
cd ~/Desktop/anima          # Mac
cd $HOME\Desktop\anima      # Windows
```

然后安装依赖（国内网络建议先换成国内镜像，下载快很多）：

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

再下载录制用的浏览器：

```bash
# Mac
PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright npx playwright install chromium
# Windows（PowerShell）
$env:PLAYWRIGHT_DOWNLOAD_HOST="https://npmmirror.com/mirrors/playwright"; npx playwright install chromium
```

以上都只需要做一次。

## 二、每一集的做法（以「血压」为例，文件夹名 `hypertension`）

各集的文件夹名见 README 里的表格，比如 `gout`、`lipids`、`sleep-drive`、`heart-valves`。

### 第 1 步：拿到配音稿

每一集的文件夹里已经有一份 `配音稿.txt`（片头引子 + 每一幕旁白）。
如果你改过 `scene.js` 里的文字，重新生成一下：

```bash
node export_script.js hypertension
```

配音稿里的英文缩写和单位已经换成了读法（比如 mmHg 写成“毫米汞柱”），这样剪映朗读不会念错。

### 第 2 步：在剪映里生成配音

1. 剪映新建项目 → 左上角 **文本** → **新建文本**，把“片头”那段粘进去。
2. 选中这段文本 → 右侧 **朗读** → 选一个音色（比如“知性女声”“温柔淑女”）→ **开始朗读**，会生成一段音频。
3. 每一幕都这样做一段，共“片头 + 6 段”。
4. 选中每段音频，记下它的**时长**（秒），比如：

   | 段落 | 朗读时长 |
   |---|---|
   | 片头 | 4 秒 |
   | 第 1 幕 | 26 秒 |
   | 第 2 幕 | 23 秒 |
   | … | … |

   做完可以把这些文本删掉，只留音频。

### 第 3 步：按配音长度录画面

每一幕的秒数 = 朗读时长 + 2 秒左右留白（让画面有喘息）；片头秒数 = 片头朗读时长 + 1 秒。

```bash
# 竖版 3:4（小红书）
node record.js hypertension --ratio 3:4 --intro 5 --durs 28,25,22,33,31,29
# 横版 16:9（B 站、课件）
node record.js hypertension --intro 5 --durs 28,25,22,33,31,29
```

- `--durs` 后面是每一幕的秒数，用逗号隔开，个数要和幕数一样；写一个数（如 `--durs 30`）就是每幕都一样长。
- `--intro` 是片头标题停留的秒数，会自动加在第 1 幕前面。
- 录完会生成 `hypertension-3x4.mp4`（或 `hypertension.mp4`），还会打印一行
  “在剪映里把每段朗读放到这些时间点：片头 0:00，第 1 幕 0:05，第 2 幕 0:33 ……”

录制是逐帧渲染，电脑卡不卡都不影响画面，一集大约几分钟。

### 第 4 步：在剪映里合成

1. 把录好的 mp4 拖进剪映主轨道。
2. 把每段朗读音频拖到上一步打印的时间点（片头放 0:00，第 1 幕放 0:05……）。
3. **背景音乐**：剪映 **音频 → 音乐**，选轻柔的纯音乐（搜“治愈”“钢琴”“八音盒”），音量调到 15%～20%，末尾加淡出。
4. **字幕**（可选）：录好的视频里已经带着每一幕的旁白文字卡，一般不用再加。想要逐句滚动字幕的话，用 **文本 → 智能字幕 → 识别字幕**，识别后逐句检查专业词。
5. 右上角 **导出**：分辨率 1080P，帧率 30fps。

## 三、常见问题

- **提示找不到 ffmpeg**：重新打开终端再试；还不行就指定路径，例如
  Mac：`FFMPEG=/opt/homebrew/bin/ffmpeg node record.js ...`
  Windows：`$env:FFMPEG="C:\路径\ffmpeg.exe"; node record.js ...`
- **`npx playwright install` 下载失败**：确认用了上面的国内镜像地址；或者装了 Google Chrome 的话，可以直接用它：
  Mac：`CHROMIUM="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node record.js ...`
  Windows：`$env:CHROMIUM="C:\Program Files\Google\Chrome\Application\chrome.exe"; node record.js ...`
- **画面和声音差一点对不上**：在剪映里拖一下音频就好；差得多就调整 `--durs` 里对应那一幕的秒数重新录。
- **只想要一段不带声音的演示视频**：`node record.js hypertension --durs 25` 即可。
- **不想装任何东西**：浏览器全屏打开某一集的 `index.html`，用系统录屏（Mac：Cmd+Shift+5；Windows：Win+Alt+R）录下来，再进剪映配音。
